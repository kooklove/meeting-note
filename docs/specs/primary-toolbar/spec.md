# 상단 툴바와 전체화면 진입

## 목표

초대, 회의록 보내기, 강조와 변경 이력 보기, 온라인 미팅 조인, 설정은 이미 각자 spec에서 "메뉴에서 켜고 끈다"고만 정해져 있을 뿐 화면에 진입점이 없다. 회의록을 열면 곧바로 그 도구들에 손이 닿게 하고, 회의 중에는 목록이 아니라 회의록 자체가 화면을 채우게 한다.

## 사용자에게 보이는 결과

- 회의록을 열면 좌측 목록이 접히고 회의록이 화면 전체 폭을 쓴다.
- 좌측 상단 아이콘을 누르면 목록이 다시 나타난다.
- 상단에 아이콘들이 늘어서 있고, 각각 초대 보내기·회의록 보내기·내가 쓴 내용 강조·변경 내용 보여주기·강조 표시·온라인 미팅 조인·설정으로 연결된다.

## 승인된 범위

### 전체화면 진입과 목록 접기

- 회의록 화면(`/notes/[slug]`)에 들어가면 좌측 목록 사이드바가 자동으로 접힌다.
- 좌측 상단에 목록 펼치기 아이콘이 항상 떠 있다.
- 누르면 목록이 본문 위에 오버레이로 펼쳐진다. 바깥을 클릭하거나 다시 아이콘을 누르면 접힌다.
- 회의록을 아직 고르지 않은 목록 화면(`/`)에서는 사이드바가 지금처럼 항상 보인다. 전체화면 전환은 회의록 하나를 열었을 때만 적용된다.
- 목록이 오버레이로 떠 있는 동안에도 본문 편집은 막히지 않는다.

### 상단 아이콘 메뉴

회의록 화면 상단에 아이콘 형태로 다음 항목이 초대 보내기, 회의록 보내기, 내가 쓴 내용 강조, 변경 내용 보여주기, 강조 표시, 온라인 미팅 조인, 설정 순으로 늘어선다.

각 아이콘을 누르면 그 기능이 열린다. 각 기능의 실제 동작은 이 spec이 아니라 이미 승인된 다음 spec을 그대로 따른다. 이 spec은 배치와 진입점만 새로 정의한다.

- 초대 보내기 → [invite-and-retention](../invite-and-retention/spec.md)
- 회의록 보내기 → [meeting-note-workspace](../meeting-note-workspace/spec.md)의 회의록 전송. 이미 구현된 SendMenu와 같은 동작이며 위치만 상단 아이콘 자리로 옮긴다.
- 내가 쓴 내용 강조, 변경 내용 보여주기, 강조 표시 → [highlighting-and-history](../highlighting-and-history/spec.md)
- 온라인 미팅 조인, 설정 → [identity-and-settings](../identity-and-settings/spec.md)

내가 쓴 내용 강조와 변경 내용 보여주기는 본인 화면에서만 바뀌는 토글이므로, 켜진 상태를 아이콘 배경색으로 표시한다. 강조 표시는 "지금부터 드래그하면 형광펜이 칠해지는 모드"를 켜고 끄는 스위치이며, 켜진 동안 본문을 드래그하면 강조가 칠해진다.

설정은 별도 패널(다이얼로그)로 열린다.

## 수용 기준

1. 회의록 링크로 들어가면 좌측 목록이 보이지 않고 본문이 화면 전체 폭을 쓴다.
2. 좌측 상단 아이콘을 누르면 목록이 오버레이로 나타나고, 바깥을 클릭하면 다시 사라진다.
3. 회의록을 열지 않은 첫 화면(`/`)에서는 좌측 목록이 항상 보인다.
4. 회의록 화면 상단에 초대 보내기, 회의록 보내기, 내가 쓴 내용 강조, 변경 내용 보여주기, 강조 표시, 온라인 미팅 조인, 설정 아이콘이 모두 보인다.
5. 내가 쓴 내용 강조 아이콘을 누르면 강조가 켜지고 아이콘 배경이 바뀐다. 다시 누르면 꺼지고 배경도 원래대로 돌아온다.
6. 강조 표시 아이콘을 켠 채 본문을 드래그하면 형광펜이 칠해진다.
7. 설정 아이콘을 누르면 설정 패널이 열린다.
8. 온라인 미팅 조인 아이콘을 누르면 등록된 링크가 열린다.

## 확정된 제약과 근거

- **이 spec은 배치와 진입점만 정의한다.** 강조·이력·초대·설정·전송의 실제 동작은 각각의 기존 spec이 이미 정의했다. 같은 결정을 두 곳에 중복해서 적지 않는다.
- **전체화면 전환은 레이아웃 폭 전환이지 브라우저 Fullscreen API가 아니다.** 주소창 등 브라우저 크롬은 그대로 남는다.

## 가정

되돌리기 쉬운 선택이라 확인 없이 정했다. 어긋나면 바꾼다.

- 목록 펼치기는 오버레이 방식이다. 다시 레이아웃을 좌우로 나누지 않는다.
- 상단 아이콘 순서는 초대 보내기, 회의록 보내기, 내가 쓴 내용 강조, 변경 내용 보여주기, 강조 표시, 온라인 미팅 조인, 설정 순이다.

## 범위 밖

- 강조·변경 이력·강조 표시·초대·온라인 미팅·설정의 실제 동작. 각 기존 spec에서 다룬다.
- 회의록 전송의 Teams·메일 활성화. [meeting-note-workspace](../meeting-note-workspace/spec.md)가 다룬다.

## 미룬 결정

- 아이콘 7개가 좁은 화면에서 줄바꿈되거나 잘릴 때 어떻게 할지.

## 남은 위험

- 상단에 아이콘 7개가 한 번에 늘어서면 처음 보는 사람에게 무엇을 누르는 아이콘인지 헷갈릴 수 있다. 툴팁만으로 충분한지 실제 화면에서 확인이 필요하다.
